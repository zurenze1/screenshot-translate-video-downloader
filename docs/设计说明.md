# 产品讲解页设计说明

日期：2026-10-15。页面服务于祖仁泽次日的产品介绍，同时作为开源仓库的长期产品入口。

## 内容结构

从使用场景出发：英文页面 → 截图整理 → 留下视频片段 → 字幕水印处理 → 来自真实反馈的迭代 → 开源安装。逐字稿和网页讲述提示共用 `talk-data.js`，避免说法分叉。完整口播单独呈现在弹窗中，投屏时默认只放短标题与操作画面。

## 视觉依据

祖老大提供的视频参考采用奶油白、香槟金、飘动材质与轻微鼠标响应。这里借鉴颜色、材质和层次关系，重新制作工具球、丝绸、玻璃面板的原创概念插画；未转载参考视频或其中的人物、标志。参考只保存在开发工作区，不随网页发布。

页面以宋体标题、细线条、分章留白为骨架；功能区配合真正可操作的网页示意。图片不冒充真实软件截图，页面各演示区均标明性质。

## 图片与动效

- `assets/hero.webp`：使用内置 imagegen 工具生成的概念插画，经格式压缩用于首屏。
- `assets/social.jpg`：同一插画的分享预览图。
- `assets/mark.svg`：代码绘制的裁切角和播放符号，作为本页导航标志；Mac 软件 2.2 版也采用同系列应用图标。
- 其余截图缩略图、山景和几何动效均由本页样式绘制，不使用第三方视频片段。

主视觉生成提示词：

> Premium Chinese Mac utility product hero, original editorial 3D still, creamy ivory and champagne-gold metal. A polished command pebble / orb with one equatorial seam, three thin floating frosted-glass panels, fine scissors and crop-corner motifs, ivory silk ribbon sweeping around the orb, pale plaster architecture, warm museum daylight, tactile material details, negative space on the left. No people, text, logos, watermark, or neon. Concept artwork, not a software screenshot.

交互包括：翻译对照切换、截图框选与拖入示意文档、片段时间轴、多个水印框和独立撤销、字幕三选一、折叠故事、逐字稿复制、分章讲解与计时。网页不读取用户真实屏幕或本地文件，也不调用翻译或下载服务。

动效仅用于材质层的轻微鼠标响应、浮动提示和章节进入。提供手动关闭、系统减少动态支持；离屏或切换浏览器标签时暂停持续动画。

## Mac 软件的统一样式（2.2）

祖老大要求浮窗与网站保持一致。软件采用奶油白底、香槟金细线、深橄榄灰主按钮、宋体标题与分章标记；默认入口由圆球改为小胶囊，原生工具面板提供全屏中文和四张功能卡片。已有自定义头像继续保留。

翻译、截图中转、下载、片段截取均使用同一套 `ProductTheme`；下载保存位置单独一行，水印与字幕控件分行。卡片支持鼠标反馈和辅助功能标签，保留原生按钮、输入、滚动与键盘行为。只设置本软件的外观，不修改系统主题。原图标与旧版本仅备份在开发工作区，不随网页发布。

已在安装后的真实软件中逐个打开四个窗口，检查工具面板、文字对比度和布局；验证了中英双向粘贴自动翻译、字幕设置及撤销恢复。此次界面核验不等于重新验证所有平台下载、水印识别或全部屏幕翻译场景。

## 发布维护

GitHub Pages 以 `main` 分支的 `docs` 目录为发布源，资源全部使用相对路径，兼容仓库子路径。公开页面不包含开发工作区、原始参考视频、设备日志、令牌和 QA 截图。验证结果记录在开发工作区的核验记录中，未验证项不写成已完成。

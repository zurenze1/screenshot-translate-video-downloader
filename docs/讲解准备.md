## 先准备这三样

1. 提前打开网页。建议电脑浏览器缩放 100%，先关掉不想投屏的私密窗口。
2. 若要现场展示真实软件，先打开它、检查录屏和辅助功能权限，准备不含隐私的英文页面和截图。不要临场等首次编译、语言包或下载组件安装。
3. 视频实操使用自己有权使用的素材与可访问的链接。网络不稳定时，使用网页内置示意讲清操作即可。

## 3 分 35 秒演示路线

| 时间预算 | 讲什么 | 页面上做什么 |
|---|---|---|
| 00:00—00:25 | 自己做内容时遇到的小麻烦 | 停留首页，不急着切换 |
| 00:25—01:00 | 英文先看懂，文字与截图都能翻 | 点“全屏中文”，再恢复 |
| 01:00—01:30 | 截图选好一起拖走 | 从空白处框两三张，拖进文档区 |
| 01:30—02:05 | 好动效只留几秒 | 拖动起点和终点，看秒数变化 |
| 02:05—02:35 | 字幕自己选，水印可以多个框 | 选字幕方式，加两个水印框，再撤销 |

时间只是排练预算。正文约 850 个汉字，实际时长取决于语速与演示停顿；建议先完整试讲一遍。

## 快捷操作

- 左右方向键：上一章、下一章。在时间轴输入控件里操作时，不会误翻章。
- **N**：显示/收起本章讲述提示。提示会出现在当前屏幕，投屏时也会被观众看到；需要时再打开。
- **G**：打开完整逐字稿，支持复制全文。
- **Esc**：先关闭提示，再退出讲解；全文弹窗也可按 Esc 关闭。
- 底部计时：点击可暂停/继续，旁边的 ↺ 归零。进入讲解时开始计时。
- 顶部“动效”：暂停装饰动画；系统开启“减少动态效果”时默认静态显示。

## 介绍效果时的准确说法

- 网页是交互示意，真实翻译、下载与文件操作在已安装的 Mac 软件里完成。
- “原画质”是优先拿平台提供的最高可用画质；去水印、抹字幕需要重新编码。
- 填平可能留痕，不能还原被水印或字幕挡住的细节；裁掉字幕会改变画幅。
- 按段下载和在线预览取决于网站支持，可能读取相邻关键帧。不要承诺所有链接都支持。
- 当前是源码安装版本，苹果芯片、macOS 14 起；离线翻译要求 macOS 26 和语言包。
